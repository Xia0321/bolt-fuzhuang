# PINSO 商品采集（Chrome 插件）

在自己的浏览器里打开商品详情页，点插件图标，把页面交给后台的「商品导入」。页面是运营自己的浏览器正常打开的，
不会被亚马逊反爬拦截，也能采集抖音、小红书这类必须登录、由脚本渲染的页面。解析、AI 补全、翻译、入库仍由导入服务完成。

## 安装

1. Chrome 地址栏打开 `chrome://extensions`，打开右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录（`deploy/product-importer/extension`）
3. 建议点工具栏的拼图图标，把「PINSO 商品采集」固定到工具栏

## 使用

1. 先在后台打开一次「商品目录 → 商品导入」（插件会记住这个页面的地址）
2. 在商品详情页点插件图标，右上角提示「已采集」后会自动切到商品导入页并开始抓取
3. 其余步骤与贴链接导入相同

## 工作方式

- `background.js`：点图标时取出当前页面 HTML（去掉样式、图标，保留脚本里的商品数据），gzip 后存入插件存储，打开导入页
- `importer.js`：运行在导入页（`https://pinso.top/importer/*`），把采集结果通过 `postMessage` 交给页面；页面调用
  `/api/scrape` 时带上 `htmlGz`，服务器直接解析这份页面，不再请求对方网站
- 采集结果 10 分钟内有效，页面确认收到后删除

修改插件代码后，在 `chrome://extensions` 里点插件的刷新按钮即可生效。
